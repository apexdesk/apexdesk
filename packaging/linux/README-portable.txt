ApexDesk for Linux, portable
============================

Run ./apexdesk from this folder: nothing to install. Settings, templates
and recovery files are kept in the "data" folder next to it (the file
named "portable" asks for that), so the folder can live on a USB stick.
Delete "portable" to keep them in ~/.config/apexdesk instead.

Needs a 64-bit x86 Linux with glibc 2.31 or newer (Ubuntu 20.04,
Debian 11, Fedora 32 and later), X11 or Wayland, and OpenGL or Vulkan.

Spelling uses the system's Hunspell dictionaries (/usr/share/hunspell).
Video and sound in presentations play through GStreamer, if installed.
