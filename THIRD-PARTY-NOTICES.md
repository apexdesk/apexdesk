# Third-Party Notices

ApexDesk is proprietary software (see LICENSE), but it is built on many open-source Rust crates. This file lists every crate that compiles into the `apexdesk` binary as a normal (non-dev, non-test) dependency, grouped by the permissive license each one offers, plus the ECMA-376 preset shape data, a vendored `epaint` patch and pdfium's standard 14 fonts.

Generated by `scripts/third_party_notices.py` from `cargo metadata` and the local `~/.cargo/registry` cache — 626 crates. Re-run the script after dependency changes; do not hand-edit the crate lists below.

## ECMA-376 preset shape geometry

`crates/apex-doc/data/preset-shapes.xml` holds the preset shape geometries from ECMA-376 Part 1 (Office Open XML), `presetShapeDefinitions.xml`, with adjust handles and white space stripped. Copyright Ecma International; used as the ECMA International standard permits implementers to use it, not under an open-source license.

## vendor/epaint

`vendor/epaint` is a local copy of the `epaint` crate (part of the `egui` project) 0.36.2, used through `[patch.crates-io]` (see `vendor/README.md` for the two changes made). Upstream `epaint` is MIT OR Apache-2.0, like the rest of the egui workspace; this local copy does not bundle a separate LICENSE file, so no crate-specific copyright line is reproduced here beyond the MIT and Apache-2.0 texts already included below for the crates.io copies of `egui`, `ecolor`, `emath` and related crates.

## pdfium's standard 14 fonts

The program has built in pdfium's fonts for the standard 14 PDF fonts (`crates/apex-io/src/pdf/render/std14`, BSD-3-Clause, Copyright 2014 The PDFium Authors), so that its own PDF renderer draws them as pdfium (the PDF engine of the Chromium project) does. pdfium itself is not distributed: it is only a development tool (`tools/pdfium-fetch.sh`) that pages are compared against.
