# What the macro editor knows of the language and the object model: the
# Object Browser (F2), completion, parameter info, case and F1 help.
# Only what the interpreter runs. A class, then its members:
#   class Name | help
#   p Property: Type | help        (read and write)
#   r Property: Type | help        (read only)
#   m Method(Params): Type | help  (the type it returns, if any)
#   e Event(Params) | help
#   f Function(Params): Type | help
#   c Constant = value | help
#   k Keyword | help
