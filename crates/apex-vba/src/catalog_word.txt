# What the macro editor knows of Word's object model: the Object Browser
# (F2), completion, parameter info, case and F1 help in a Word macro.
# Only what the interpreter runs. The language's own classes (Keywords,
# VBA, Constants, Collection, Dictionary, FileSystemObject, Debug...) come
# from catalog.txt. Same format as catalog.txt:
#   class Name | help
#   p Property: Type | help        (read and write)
#   r Property: Type | help        (read only)
#   m Method(Params): Type | help  (the type it returns, if any)
#   f Function(Params): Type | help
#   c Constant = value | help
# Positions are characters of the text, a paragraph mark counting as one.
# A line is a paragraph: there is no page layout while a macro runs.
